6AI 字段识别逻辑

核心在 src/utils/fieldMapper.js：维护一张中英文同义词词典，对每列表头做相似度匹配。下方是可运行的演示——输入你的表头，看看会被映射到哪个标准字段。

算法说明：①精确相等直接命中（score=1）；②包含关系 0.85；③按字符交集比例计算相似度，阈值 ≥0.5 才采纳；④同一目标字段不重复占用。配置 AI_API_KEY 后改用 LLM 语义映射，失败自动回退规则引擎。

8运行与关键说明

启动步骤

① npm install 安装依赖（含原生模块 better-sqlite3，需本地编译环境）
② 复制 .env.example 为 .env（可选填 AI 配置）
③ npm start → 访问 http://localhost:3000

设计亮点

• 字段识别与人工确认分离，安全可控
• 生成与保存解耦（/generate 不落库）
• 模板风格配置化（v1/v2/v3 配色字体可切）
• 纯英文单证内容，贴合国际贸易惯例

⚠ 已知问题（来自 zip 内 server_err.txt）：
日志显示启动时报 EADDRINUSE :::3000 —— 端口 3000 被占用导致服务未起来。解决：先结束占用 3000 端口的进程，或改 .env 的 PORT 后重启。此外，better-sqlite3、pdfkit 为含原生编译的依赖，需保证 Node 构建工具链可用。
